# Run and deploy your Next.js app

This contains everything you need to run your app locally with server-side rendering support via Next.js.

View your app in AI Studio: https://ai.studio/apps/673c2d9c-6c78-4170-a4d9-a9daacc6f973

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app in development mode:
   `npm run dev`
4. Build for production:
   `npm run build`
5. Start production server:
   `npm run start`
